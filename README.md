# AFOP Gear Swap Tool
A lightweight GUI utility for swapping gear models in **Avatar: Frontiers of Pandora** using `.mgraphobject` file replacement.

<img width="1400" height="895" alt="image" src="https://github.com/user-attachments/assets/2ea4208d-ca03-46fe-8158-180cf6aeb4d6" />

## How to use
1. **Set your mod folder** — point it to your `blue/graph objects/gear` directory. **(this is your output folder)**
2. **Set your source file** — browse to the extracted `.mgraphobject` file from the game files. **(can be located anywhere on your system)**
3. **Pick a SOURCE item** from the left list — this is the model you want to apply.
4. **Pick a TARGET item** from the right list — this is the gear slot you want to replace.
5. Check the centre panel for any warnings/errors, then click **EXECUTE SWAP**.

The tool will copy your source `.mgraphobject` into the mod folder, renamed to match the target slot. The game will then load the source model in place of the target gear.
